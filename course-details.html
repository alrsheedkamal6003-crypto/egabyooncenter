التطوير الشامل لتطبيقات الويب والموبايل
(Full-Stack Developer)

دورة احترافية متكاملة تبدأ معك من الصفر وتأخذك خطوة بخطوة لاحتراف هندسة وتصميم وبناء المواقع الإلكترونية وتطبيقات الهواتف الذكية باستخدام أحدث التقنيات ولغات البرمجة (HTML5, CSS3, JavaScript, VB.NET, Flutter) لبناء مسار مهني قوي ومطلوب عالمياً.

ماذا ستتعلم في هذه الدورة التخصصية؟

  • إتقان بناء واجهات مستخدم (UI) احترافية وعصرية متجاوبة مع جميع الشاشات باستخدام HTML5 و CSS3 وتقنيات Flexbox و Grid.
  • برمجة تفاعل المواقع والمنطق البرمجي (Logic) بشكل متقدم باستخدام JavaScript و ES6+.
  • تصميم وإنشاء قواعد بيانات قوية (Relational Databases) وربطها بالتطبيقات بأمان تام.
  • احتراف بناء تطبيقات سطح مكتب قوية لإدارة المؤسسات وأنظمة نقاط البيع (POS) باستخدام VB.NET.
  • تعلم تطوير تطبيقات الهواتف الذكية (Android & iOS) باستخدام إطار العمل القوي Flutter.
  • رفع المواقع واستضافتها مجاناً ومدفوعاً (GitHub Pages, Vercel, وغيرها) مع ربط الدومين.
  • إدارة إصدارات الأكواد البرمجية والمشاريع باستخدام نظام Git و منصة GitHub للعمل كفريق.
  • تنفيذ مشروع تخرج متكامل (نظام إدارة متكامل أو موقع لشركة) يضاف لمعرض أعمالك (Portfolio).

لمن هذه الدورة؟ و ما هي المتطلبات؟

لا تشترط هذه الدورة أي خبرة برمجية سابقة أو خلفية تقنية.

الفئة المستهدفة: المبتدئين الراغبين في دخول عالم البرمجة، المطورين المبتدئين الساعين لترتيب أفكارهم، طلاب الحاسب الآلي والموظفين الباحثين عن تحسين دخلهم بمهارة مطلوبة.

المتطلبات: كل ما تحتاجه هو جهاز كمبيوتر محمول (أو حتى هاتف ذكي لمتابعة الأساسيات الأولى)، اتصال جيد بالإنترنت، والأهم من ذلك: شغف كبير للتعلم وتطوير مهاراتك لمستوى الاحتراف.
